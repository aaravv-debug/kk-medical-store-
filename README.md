# K.K. Medical Store & Multi-Services Hub

Official web application for **K.K. Medical Store & Multi-Services Hub**, located at Shop No. E-9, Vande Mataram Homes, New Ranip, Ahmedabad.

## 🚀 Key Highlights & Departments
- **Prescription Pharmacy**: 100% genuine allopathic medicines with printed GST bills.
- **Natural Ayurvedic Care**: Classical Asava, Arishta, herbal oils, and pain formulations.
- **Digital Colour Print & Xerox Hub**: High-speed digital laser printing, certificate lamination, and WhatsApp print queue.
- **Flagship Ayurvedic Bestsellers**: 
  - *KK Maha Narayan Sandhivata Tailam* (100ml medicated pain relief oil).
  - *KK Fast Action Ayurvedic Pain Balm* (50g herbal pain relief).
- **Interactive Print & Xerox Cost Calculator**: Instant price estimations with WhatsApp order routing.
- **Instant WhatsApp Ordering & Prescription Upload**: Integrated modal for seamless customer interaction.

## 🛠️ Zero-Config Deployment

This repository is optimized to deploy without any build configuration errors on all major hosting platforms:

### 1. Vercel / Netlify / Cloudflare Pages / GitHub Pages
- **Framework Preset**: Other / Static HTML
- **Root Directory**: `./` (Root)
- **Build Command**: *(leave empty)*
- **Output Directory**: `./` (Root)

### 2. Node.js Hosting (Render / Railway / Heroku / Fly.io)
- **Start Command**: `npm start` (or `node server.js`)
- Dynamic port detection (`process.env.PORT`) is built-in.

## 💻 Local Development

To run locally:
```bash
# Clone the repository
git clone https://github.com/aaravv-debug/kk-medical-store-.git

# Navigate to project folder
cd kk-medical-store-

# Start local preview server
npm start
# or: node server.js
```
Open [http://localhost:5173](http://localhost:5173) in your browser.
